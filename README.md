## 🚀 安装与使用方法

### Loon
1. 打开 **Loon** App。
2. 进入 **配置 (Configuration)** -> **插件 (Plugin)**。
3. 点击右上角 **`+`** 号，选择 **从 URL 添加插件**。
4. 粘贴对应的 Raw 或 jsDelivr CDN 链接并启用。

### Stash
1. 打开 **Stash** App。
2. 进入 **覆写 (Overrides)** 页面。
3. 点击右上角 **`+`** 导入，选择 **从 URL 下载**。
4. 粘贴对应的 Raw 或 jsDelivr CDN 链接保存并启用。
